# Codex

这是 Rabbrtf 的 Codex 专属仓库，用于保存适合版本控制和公开共享的项目代码、说明文档与可复用配置。

## 使用原则

- 本地生成或整理的项目文件，首先保存在固定工作区：`/Users/rf/Documents/Codex Work Space`。
- 只有经过确认、适合公开的内容才提交到本仓库。
- 禁止提交密码、API Key、访问令牌、私钥、WireGuard 配置、SSH 密钥、Cookie、个人身份信息或其他敏感数据。
- 提交前检查变更内容，确保日志、截图和配置文件已脱敏。

## 建议目录

- `projects/`：项目代码
- `docs/`：说明文档
- `skills/`：可公开的 Codex 技能
- `scripts/`：通用脚本

> 本仓库当前为公开仓库。敏感资料应只保存在受控的本地位置，不应上传。
